# 校园网助手体验升级规格

## 产品目标

首次安装后明确告诉用户下一步是访问 `10.10.10.2` 并登录；日常设置只展示账号与自动化等高频选项；在认证页提供可随时恢复原网页的现代登录界面。

## 设计方向

- 全部界面以 WinUI 3（Windows 11 设计体系）为唯一视觉基准：官方 `microsoft-ui-xaml` 主题资源提供权威颜色、4px 控件圆角 / 8px 浮层圆角、83/167/250ms 动效时长与 `cubic-bezier(0,0,0,1)` 标准曲线；`WinUIonWeb`（TEMP/winui/WinUIonWeb-master）提供可直接移植的控件实现与动画细节。
- 登录页与欢迎页采用"动画角色"品牌方向（TEMP/登录界面 参考项目）：CSS 纯画的四个几何角色承担品牌演出，控件仍严格使用 WinUI 规格，保证全局观感一致。
- 字体栈以 `Segoe UI Variable` / `Segoe UI` 打头，中文回退微软雅黑；图标统一使用 Segoe Fluent Icons 字形（内置 `fonts/segoe-fluent-icons.ttf`，优先取系统字体），单色、无底色块。
- 控件遵循微软规范：Button 按压只变填充不缩放、ToggleSwitch 40×20 细轨道 12px 圆点（悬停放大）、TextBox 聚焦显示 2px 底部强调线、焦点为 2px 外描边 + 1px 内描边双色框、设置行使用 SettingsCard 式 4px 圆角卡片按 4px 间距堆叠。
- 颜色使用官方语义令牌（Text/Control/Card/Layer fill 分层 + 系统语义色）并完整支持浅色、深色、高对比与强制颜色模式。
- 动画只用于状态与转场（入场使用 0.45s decelerate 上移入场、 flyout 167ms、对话框 250ms scale 1.05→1），支持 `prefers-reduced-motion`。
- 自定义背景支持纯色、每日壁纸（必应，需可选主机授权）与自定义图片三种来源，提供模糊/遮罩/缩放/填充方式/九宫格焦点调节；壁纸下文字自动叠加玻璃遮罩，遮罩强度可独立调节（0.4–1.4）并跟随材质预设，门户表面跟随整体浅/深主题选择遮罩；门户侧图片仍只进入 closed Shadow DOM。
- 材质预设提供纯色、Mica、Acrylic 轻度、Acrylic 强与自定义五档，作用于导航、头部与浮层；内容区不堆叠成多层玻璃卡片。

## 页面规格

### 连接可靠性

- 后台以“检查中、需要登录、登录中、等待重试、需要处理、已在线、未连接”表达连接阶段。
- 所有登录入口共享一个进行中的认证任务，避免弹窗、认证页、启动登录和定时守护重复请求。
- 临时网络失败使用 30 秒起步、5 分钟封顶的指数退避；凭据或设备冲突错误暂停自动重试。
- 连接状态与短时跳转保护使用 `storage.session`，不依赖可能随后台终止而丢失的全局变量。
- 自定义背景在本机压缩后限制为约 3 MB，并在设置页显示当前预计占用。

### 首次安装欢迎页

- 只在 `chrome.runtime.onInstalled` 的 `reason === "install"` 时打开。
- 首屏主标题为“先登录校园网”，显著显示 `10.10.10.2`。
- 主操作“打开 10.10.10.2 并登录”在当前标签页进入认证页；次操作打开设置。
- 用三个真实步骤说明：打开认证页、输入校园网账号、登录请求暂存并确认。

### 设置页

- 首屏保留账号管理、自动化设置和外观定制。
- 账号编辑默认展示名称、运营商、账号、密码；抓包网络字段留在账号内的折叠区域。
- 外观提供“跟随系统 / 浅色 / 深色”三档主题、完整强调色取色器（256px 光谱 + 明度滑条 + hex 即时生效 + 八色预设）、材质预设与遮罩强度、纯色 / 每日壁纸 / 自定义图片三种背景来源和实时预览；图片在本机缩放压缩（上限 1.9 MB 字符，受浏览器内联样式单值上限约束），允许调节模糊、遮罩、缩放、填充方式与九宫格焦点位置；每日壁纸启用时才请求必应主机授权并本地缓存；品牌面板颜色可跟随强调色或独立指定，底部图案在网格/圆点/斜线/菱形交叉/无间切换。
- 外观提供“页面过渡动画”（入场/滑动/钻取/无）与“导航窗格位置”（左侧/顶部，窄屏恒为底部 Dock）；桌面侧栏提供折叠按钮，可收合为仅图标的 48px 栏。
- 外观提供“在线信息显示”：经典为默认值，完整默认展开详情，简化只保留非敏感操作，隐藏只保留注销。
- 设置页采用 WinUI NavigationView 平铺布局：桌面为左侧导航窗格（选中项带 3×16 强调色指示条），窄屏切换为底部 Dock；低频配置折叠在 Expander 式高级设置中。
- 高级设置使用原生 `<details>/<summary>`，容纳网关地址、接口参数、抓包 URL 导入、跳转保护、门户接管开关、请求日志和恢复默认。
- 高级设置中的“门户诊断模式”卡默认关闭，明确写出“仅在本机记录脱敏后的页面结构和操作类型”，并明确不会记录输入值、密码、账号、IP 或 MAC。
- 诊断卡以实时状态说明开关、暂停状态，并显示本地占用（上限 1 MiB）、会话数（上限 10）和已淘汰记录数；提供 JSON 导出和清空记录操作。开关与两个操作按钮均提供至少 44px 的触控区域，状态采用 `role="status"` 和 `aria-live="polite"`。
- 导出仍提示用户在分享前复核内容；清空诊断记录属于破坏性操作，只有明确确认后才发送清空请求，取消不得改动本地记录。
- 全部设置修改后立即自动生效并持久化（外观区本就即时应用；换网关需要授权时在提交瞬间请求权限），不再依赖单独的保存按钮；保活间隔仅在保活开启时可编辑。

### 认证页接管

- 原页面 DOM 必须保留，覆盖层出现时仅视觉隐藏；“使用原始登录页”立即恢复。
- 内容脚本只能读取公开的门户 UI 配置，不能读取保存账号或密码。
- 登录界面包含账号、运营商、密码和“保存账号”；通过本地后台服务调用认证接口。
- 运营商按校园网、联通、电信、移动排列；提供重置按钮，以及使用说明、自助服务、账号激活、找回密码的学校官方外链。外链必须新开窗口并隔离 opener，扩展不嵌入或代理外部业务。
- 登录成功切换为在线状态；失败在表单内说明原因并允许重试。
- 检测到已在线页面时，经典主卡片显示状态、已用时间、总流量、自助服务、刷新和“注销并解绑 MAC”；脱敏账号、上下行流量、余额、登录时间及网络字段放在可展开详情中，不再自动弹出设置页。
- 注销前显示确认对话框，取消不得发出请求；确认后由后台执行解绑优先、完整注销回退和最终状态复核。
- 检测到验证码时不隐藏学校原始控件，只显示继续使用原始页面的提示；二维码和移动端验证码本轮不复刻。
- 若渲染或通信失败，自动撤下覆盖层并恢复原页面。
- 门户个性化入口使用 44px 点击区域、悬停提示和无障碍名称；自定义图片与每日壁纸只进入 closed Shadow DOM。
- 登录页为双栏布局：左侧为四个动画角色组成的品牌面板（网格纹理 + 模糊光斑），右侧为 WinUI 表单卡；窄屏隐藏角色面板。角色演出仅是装饰：输入账号时对视、聚焦密码时捂眼、登录失败摇头、成功笑脸与一次性撒花；`prefers-reduced-motion` 下全部静止，且任何角色相关异常都不影响认证流程。

### 破坏性操作

- 删除账号、覆盖抓包导入、恢复默认设置、清空请求记录、清空门户诊断记录和清除背景必须先确认。
- 对话框必须写明具体影响对象，支持 Escape 和键盘操作，默认焦点落在取消按钮。

## 验收条件

- 新安装弹出欢迎页，扩展更新不会重复弹出。
- 设置页低频项目默认折叠，高频项目无需展开即可使用。
- 主题选择和自定义背景会同步到欢迎页、快捷面板、设置页和认证页；门户公开配置和轻 DOM 不出现图片 Data URL。
- 认证页可以在现代界面和原始页面之间无刷新切换。
- 网页发送 `state:get` 仍被拒绝；`portal:config:get` 只返回非敏感字段。
- `portal:status:get` 只接受可信顶层门户并只返回脱敏结构化状态，不泄露原始 JSONP、Cookie 或完整账号/IP/MAC。
- 所有本地脚本通过语法检查，自动化测试全部通过。
- 取消任一破坏性操作不会发送后台变更消息。
- `kill-ai-slop` 复扫只允许保留经过人工确认的等宽日志字体。
- 并发登录只产生一个真实请求；临时失败安排一次性重试，凭据失败不安排自动重试。
