# 徐医校园网xzhmu 双语与移动端支持 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为扩展加入跟随浏览器的中英文界面切换、规范的包内语言声明，以及 Chrome 桌面和 Microsoft Edge Android 可用的响应式界面。

**Architecture:** 使用独立的运行时词典与国际化引擎统一翻译静态 DOM、动态消息和无障碍属性；后台语言服务通过严格枚举消息读写独立存储键，并把变化广播到扩展页和门户内容脚本。认证、解绑和账号状态数据流保持不变，各界面只把现有展示字符串迁移为稳定消息键。

**Tech Stack:** Manifest V3、原生 JavaScript IIFE/CommonJS 兼容模块、Chrome/Firefox WebExtension API、HTML/CSS、Node.js `node:test`、现有自制 ZIP 打包器。

**Spec:** `docs/superpowers/specs/2026-09-14-i18n-mobile-design.md`

## Global Constraints

- 简体中文产品名必须是 `徐医校园网xzhmu`，英文产品名必须是 `XZHMU Campus Network`。
- 语言偏好只允许 `auto`、`zh-CN`、`en`；默认 `auto`。
- `auto` 在中文浏览器环境解析为 `zh-CN`，其他环境解析为 `en`。
- 语言偏好使用独立 `storage.local` 键 `drcomAssistantLanguage`，不得写入主状态。
- 学校原始门户和无法可靠分类的网关原文不得翻译。
- 不改变登录、注销、终端解绑、自动登录、账号捕获确认或 Dr.COM 请求参数。
- 不引入构建器或第三方运行时依赖。
- 支持 Chrome 桌面、Edge 桌面、Edge Android 和现有 Firefox 包；不宣称支持 Chrome Android。
- 版本在功能验收前保持 `1.1.0`。

- [ ] **Step 3: 实现最小词典和国际化引擎**

`CRX/i18n-messages.js` 使用 UMD 导出词典；`CRX/i18n.js` 使用同样模式，并实现严格偏好归一化：

```js
const VALID_PREFERENCES = new Set(["auto", "zh-CN", "en"]);

function normalizePreference(value) {
  return VALID_PREFERENCES.has(value) ? value : "auto";
}

function resolveLanguage(preference, browserLanguages = []) {
  const normalized = normalizePreference(preference);
  if (normalized !== "auto") return normalized;
  return browserLanguages.some((value) => /^zh(?:-|$)/i.test(String(value))) ? "zh-CN" : "en";
}
```

`t` 先取当前语言，再取中文回退，最后返回键名；`apply` 只使用 `textContent` 和 `setAttribute`。

- [ ] **Step 3: 实现语言服务并接入后台依赖装配**

服务只操作常量键：

```js
const LANGUAGE_STORAGE_KEY = "drcomAssistantLanguage";

async function setPreference(value) {
  if (!["auto", "zh-CN", "en"].includes(value)) throw new Error("不支持的界面语言");
  await storage.set({ [LANGUAGE_STORAGE_KEY]: value });
  await broadcast(value);
  return value;
}
```
