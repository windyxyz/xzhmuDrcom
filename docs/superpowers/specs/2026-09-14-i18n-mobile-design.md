# 徐医校园网xzhmu 双语与移动端支持设计

## 目标

为扩展加入可在界面内切换的简体中文与英文，并让安装包向 Chrome、Microsoft Edge 和 Firefox 正确声明支持的语言。首次安装跟随浏览器语言；用户可以改为固定中文或英文，选择在当前浏览器配置文件中持久保存。

产品名称统一为：

- 简体中文：`徐医校园网xzhmu`
- 英文：`XZHMU Campus Network`

本次兼容 Chrome 桌面、Microsoft Edge 桌面与 Microsoft Edge Android。Chrome Android 当前没有面向普通扩展的正式安装承诺，因此文档不宣称支持 Chrome Android。

## 范围

双语覆盖扩展自己绘制和控制的界面：

- 快捷弹窗；
- 设置页；
- 首次欢迎页；
- 现代化校园网登录页及在线状态页；
- 扩展生成的确认框、状态说明、提示消息、页面标题与无障碍标签。

学校原始门户页面不翻译。网关直接返回且扩展无法可靠分类的原始错误消息保持原文，避免翻译改变故障含义。

登录、注销、终端解绑、自动登录、账号捕获确认和 Dr.COM 参数不在本次变更范围内。

## 语言模型

用户语言偏好使用三个值：

- `auto`：默认值，跟随 `navigator.languages`、`navigator.language` 或浏览器国际化 API；中文语言环境使用简体中文，其余环境使用英文；
- `zh-CN`：固定简体中文；
- `en`：固定英文。

偏好存入独立的 `storage.local` 键，不并入包含账号和大背景图的主状态，避免语言切换放大存储写入。没有存储权限、读取失败或值无效时安全回退到 `auto`。

所有扩展页面与现代化门户共享同一语言解析规则。切换语言后当前页面立即更新，并广播给其他已打开的扩展界面；新打开的页面读取已保存偏好。页面根节点同步更新 `lang` 与 `dir`，当前仅支持从左到右的中文和英文。

## 资源与清单

新增一个无第三方依赖的共享国际化模块，提供：

- 解析浏览器语言与用户偏好；
- 按键读取文案和替换参数；
- 应用静态 DOM 的文本、属性和页面标题；
- 保存语言偏好并通知当前界面重新渲染；
- 在缺少键时回退到简体中文，并在开发环境留下不含敏感数据的警告。

`_locales/zh_CN/messages.json` 与 `_locales/en/messages.json` 提供清单名称、描述和默认标题。Chrome 与 Firefox 清单都增加 `default_locale: "zh_CN"`，名称、描述及操作标题改为 `__MSG_*__` 占位符。运行时界面词典由共享模块维护；清单资源与运行时资源使用相同键名和测试约束，避免品牌文案漂移。

共享模块按现有 IIFE/global API 风格加载，不引入打包器。Chrome、Firefox 内容脚本顺序、页面脚本引用、发布白名单和语法检查清单同步更新。

## 界面入口

设置页提供完整的“跟随浏览器 / 中文 / English”选择器，作为语言偏好的主设置入口。

快捷弹窗、欢迎页和现代化门户页提供紧凑语言按钮，便于用户在看不懂当前语言时直接切换中文或英文。紧凑按钮只在中文和英文之间切换；返回“跟随浏览器”可在设置页完成。按钮具有双语无障碍名称，不依赖当前语言才能识别。

语言切换不提交账号表单、不改变焦点中的账号或密码、不触发登录，也不重建现代化门户根节点。动态区域通过现有渲染函数重新输出，输入值和连接状态保持不变。

## 动态消息策略

展示层使用稳定消息键生成扩展自有文案。已知连接阶段、账号校验、设置保存、捕获确认、诊断和外观提示都映射为中英文。

后台暂不做大规模“字符串改错误码”重构。对已有稳定状态字段优先按状态字段翻译；仅有字符串的历史返回值通过有限、精确的已知消息映射翻译。未知网关消息原样展示并添加本地化上下文标题，不通过模糊匹配改写。

## 移动端兼容

继续使用 Manifest V3 和当前所需 API，不新增桌面专属权限。针对 Microsoft Edge Android：

- 快捷弹窗、设置页和现代门户在 320、360、390 像素宽度下无水平溢出；
- 交互控件保持至少 44 CSS 像素的触控高度；
- 安全区使用 `env(safe-area-inset-*)`；
- 语言选择器、确认框和密码输入在软键盘出现时仍可滚动到；
- hover 仅作为增强，核心操作支持触控和键盘；
- 不依赖侧栏、桌面窗口尺寸或仅桌面可用的扩展 API。

“支持 Edge 手机版”表示代码、清单和响应式界面兼容 Edge Android 的扩展运行环境；实际上架资格与商店分发范围仍以 Microsoft Edge Add-ons 审核结果为准。

## 错误处理与安全

- 翻译资源缺失不会阻止页面初始化或登录；回退中文后继续运行。
- 存储失败只保留当前页面的临时选择，并显示本地化提示。
- 翻译参数始终经 `textContent` 或属性安全赋值，不进入未转义 HTML。
- 语言广播只传递枚举值，不携带账号、密码、URL 或诊断内容。
- 内容脚本不能借语言接口修改账号与主设置；语言偏好使用专用、严格校验的消息路径。

## 测试与验收

严格采用测试驱动：先写失败测试，再实现最小功能。

测试覆盖：

- Chrome 与 Firefox 清单可解析，并声明 `zh_CN`、英文资源和本地化品牌名；
- 浏览器语言为中文时 `auto` 解析中文，其他语言解析英文；
- 无效或读取失败的偏好回退 `auto`；
- 设置页可选择三种模式，其他页面可中英文快捷切换，刷新后保持选择；
- 静态文字、动态状态、确认框、标题和无障碍标签同步切换；
- 切换语言不会清空表单、触发登录或改变连接状态；
- 未知翻译键和未知网关原文采用规定的安全回退；
- 320、360、390 像素视口无水平溢出，关键控件满足触控尺寸和安全区要求；
- Chrome、Firefox 打包均包含所有语言资源且无开发文件泄漏。

每个阶段运行相关单元测试，最终运行完整 `npm run verify`、两类 ZIP 打包及发布白名单检查。实际 Edge Android 安装与校园网登录属于人工验收，不使用真实账号加入自动化测试。
