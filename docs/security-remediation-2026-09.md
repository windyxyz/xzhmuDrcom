# 2026-09 安全整改登记

本登记基于用户提供的 `docs/security-audit-2026-09.md` 第三轮审计报告整理。原始审计报告保持为取证资料；本文件记录本分支的整改状态、接受风险和延期项。

## 状态口径

- 已修复：代码与测试均已覆盖，原问题路径已被阻断或删除。
- 部分缓解：高风险触发链已被切断，但仍保留受产品体验约束的残余风险。
- 接受风险：当前产品明确保留该行为，并通过文档、告警或权限边界告知用户。
- 延期：用户已确认本轮不做结构性改造，保留后续单独设计。

## 明确延期项

- 暂不把门户内嵌密码框迁移到扩展自有页面。
- 暂不把 closed Shadow DOM 宣称为凭据隔离方案；宿主脚本仍可能通过页面级事件观察真实用户输入节奏或其他环境信号。
- 暂不取消保存密码、自动登录或默认 Dr.COM HTTP GET 协议；这些作为兼容体验风险登记在 `SECURITY.md`。
